来来来，记录下最近的事情

这个周末过得还挺充实，最近在基于 Warp 做二次开发，写一个自用的终端，这周末算做出了第一个可用版本

为什么要二开呢，因为司内的 terminal 真的太难用了，没有 AI 功能，而且万年不更新，真的太旧了

而 Warp 是我个人一直喜欢用的，但是连接线上服务器或者 pod 的时候，司内网络环境比较复杂，要走跳板机二次转发，原生 Warp 的 warpify 不能正常工作

这周末用自用 Codex Pro 和司内的 AI 资源轮番上阵，终于解决了，这个 warpify 的路径还挺多，Warp 改了很多版，算是学到了一些东西

另外就是要支持 ZMODEM 协议，虽然是上古的传输文件协议，但是在司内的复杂网络环境下非常好用，首先你是没法穿透的，日常传文件的常用命令不能用，虽然有司内的协议但是也非常难用，真不如 sz rz 直接搞定

ZMODEM 的原理是直接用终端连接的字节流传输文件，所以只要你能 SSH 上去，那就能传输文件

但是比较现代的终端都不支持了，我花了挺多劲才把 Warp 调试到让我比较满意的效果

然后就是 AI 相关的能力了，我没法忍受我的终端不能接入终端，我这个自用项目也直接叫做 Agenterm，意味能与 Agent 无缝结合的 Terminal

具体逻辑并不是让他具有 AI 能力，而可能是提供 MCP 让另外的 Coding Agent 来操作这个 Terminal

这样就不至于像一个黑盒一样让 AI 直接执行线上命令，我只会让他提供命令，让我自己按回车执行

并且 Warp 的 block 抽象也很适合让 Agent 理解，而是要做「读取最近 200 行」这种丑陋的工具

这周另外一件事就是写 blog，最近在想两篇，一篇是回忆大半年前的一场恋爱，一篇是记录最近开学前我弟（比我小 11 岁，小升初暑假）过来和我这边住了两周的故事（宴请儿时的自己了属于是）

虽然都还没有完成，但是大纲写的差不多了，最近在回忆里面的各种细节，要写哪些事情，如何排布

我感觉写 blog 必须要对每件事一遍遍想怎么说比较好，就像大模型一样，你问同一个东西，每次都会生成不同的表述方法，虽然都是对的，但是我要挑选出最合适，衔接最顺畅的结构，把前后片段串联在一起

另外还有一件事是组里居然可以报销自费外部模型订阅了，实在是太感动了，司内虽然给了几千块的额度，也能用 GPT Claude 等等，但是是 API 计费的，花的很快，不如 Subscription

另外一提这周末也用了用 HY4，比我想象的好，并且司内免费用，但是也不是无限的，应该是每天也有额度用多了会 429
