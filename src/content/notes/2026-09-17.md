很怀念大学时候天天学新东西的日子，今天开始学习之前 Star了很久的项目 [Learn Claude Code](https://learn.shareai.run/)

一共有 20 个 session，不过我今天连第一个都没有完成，只写了一个很简单的 [Conversation Loop](https://github.com/nickxudotme/learn-coding-agent-go/tree/7f91bc144dee7b9000be0f652956c1be07af19f0)

因为我没打算直接照抄代码，他给的是 Python 的，我打算按照自己的理解使用 Go 重写一遍，而且不借助 Coding Agent

这就挺耗时间了，并且他使用 Anthropic 的 SDK，我打算用 OpenAI 的配合本地 Ollama，折腾了挺久

现在的 OpenAI SDK 变化挺大的，现在不是 `client.Chat.Completions.New` 了，而是 `client.Responses.New` ，签名设计更加友好

也不需要自己维护 messages，甚至还有更加专业 `Conversation` 类型

明天继续
